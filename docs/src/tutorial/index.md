# Josh tutorial

This tutorial follows the current vertical slice. It starts at the interactive prompt, separates commands from expressions, moves values into argv, captures output, builds pipelines, and ends with a script.

Only examples labeled **Runnable example** are instructions; each one runs against the current build. The tutorial does not ask you to run syntax Josh does not have.

Before starting, build Josh using [Install and build](../welcome/install.md). Commands use common Unix programs such as `printf`, `tr`, and `sh`.
